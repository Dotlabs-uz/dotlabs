# Content & Media — единая точка управления

Весь контент и медиа сайта редактируются здесь. Бэкенда и админки нет — правки делаются в коде.

## Структура

| Файл | Что править |
|------|-------------|
| **site.ts** | Мета (title, description), бренд (имя, цвета), навигация, футер (ссылки, соцсети, адрес, копирайт). |
| **hero.ts** | Блок Hero на главной: бейдж, заголовок, подзаголовок, кнопки. |
| **home-sections.ts** | Интро-баннер, текст и медиа отзывов на главной, заголовок секции отзывов, блок CTA (заголовок, подзаголовок, кнопка). |
| **projects.ts** | Список проектов (карточки) и детали по каждому slug: картинка, описание, длительность, команда, технологии, польза для клиента, видео сторителлинга. |
| **team.ts** | Команда: фото, имя, роль, био, соцсети. |
| **testimonials.ts** | Отзывы (цитаты, авторы, фото) — используются где угодно. |
| **services.tsx** | Услуги: название, описание, теги, ключ иконки (Monitor, Smartphone, Database, Figma). |

## Импорт в коде

Используйте один вход:

```ts
import {
  SITE_META,
  BRAND,
  NAV_LINKS,
  PROJECTS,
  getProjectBySlug,
  TEAM_MEMBERS,
  TESTIMONIALS,
  SERVICES,
  FOOTER_NAV,
  FOOTER_SOCIAL,
  HERO,
  INTRO_BANNER,
  HOME_TESTIMONIALS,
  CTA_SECTION,
} from '@/content';
```

Для обратной совместимости то же самое реэкспортируется из `@/lib/constants`.

## Проекты

- **PROJECTS** (или **PROJECTS_LIST**) — массив для карточек на главной; у каждого элемента должен быть уникальный **slug**.
- **PROJECT_DETAILS** — объект `slug → детали`: длительность, команда, технологии, польза для клиента, **storytellingVideos** (url, title, duration, caption).
- Страница проекта: `getProjectBySlug(slug)` возвращает объединённые данные.

Добавление проекта: добавить объект в **PROJECTS_LIST** и запись в **PROJECT_DETAILS** с тем же **slug**.

## Медиа

- Изображения и видео задаются URL (внешние или из `/public`).
- В проектах: **image** в базе, в деталях — **storytellingVideos[].url** и при необходимости **thumbnail**.
- Для локальных файлов используйте путь от корня сайта, например `/images/team/photo.jpg` (файл в `public/images/team/`).
